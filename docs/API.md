# Описание API

## Аутентификация
| Метод | Маршрут | Доступ | Описание |
|-------|---------|--------|----------|
| POST | `/api/auth/login` | Все | Вход (username, password) → JWT |
| POST | `/api/auth/register` | Все | Регистрация (username, password) → JWT |

## Ресурсы
| Метод | Маршрут | Доступ | Описание |
|-------|---------|--------|----------|
| GET | `/api/resources` | Все | Каталог (поиск ?search=, фильтр ?location=) |
| GET | `/api/resources/:id` | Все | Карточка ресурса |
| GET | `/api/resources/:id/availability?date=YYYY-MM-DD` | Все | Занятые интервалы на дату |

## Бронирования
| Метод | Маршрут | Доступ | Описание |
|-------|---------|--------|----------|
| POST | `/api/bookings` | Пользователь | Создание (заголовок `Idempotency-Key` обязателен) |
| GET | `/api/bookings/my` | Пользователь | Свои брони |
| GET | `/api/bookings/:id` | Владелец / Админ | Просмотр записи |
| POST | `/api/bookings/:id/cancel` | Владелец / Админ | Отмена (причина обязательна для админа) |

## Администрирование
| Метод | Маршрут | Доступ | Описание |
|-------|---------|--------|----------|
| GET | `/api/admin/bookings` | Админ | Все брони с фильтрами (?status=, ?date=) |
| POST | `/api/admin/bookings/:id/cancel` | Админ | Отмена чужой брони (причина обязательна) |
| GET | `/api/admin/audit` | Админ | Журнал аудита |

## Коды ответов
- `400` — неверные поля, нарушены правила времени.
- `401` — нет или истек JWT.
- `403` — нет прав (не админ).
- `404` — запись не найдена или недоступна.
- `409` — конфликт времени или повтор ключа с другими данными.
- `500` — непредвиденная ошибка (с `traceId`).
